# modian

个人代码仓库，用于存放和同步各种项目文件。

## 目录结构

```
modian/
├── .gitignore      # Git 忽略规则
├── .vscode/        # VSCode 工作区配置
└── README.md       # 本文件
```

## 使用方式

### 克隆仓库

```bash
git clone https://github.com/MBO2006/modian.git
```

### 日常同步

```bash
# 添加所有更改
git add .

# 提交
git commit -m "更新说明"

# 推送到 GitHub
git push
```

### 拉取最新代码

```bash
git pull
```
