二极管电路

半波整流电路

工作原理：
  • 交流正半周：二极管导通，电流流过负载
  • 交流负半周：二极管截止，无电流
  • 输出：脉动直流（只有正半周）
V_out = V_in × 0.45（有效值）
或 V_out = V_peak / π（平均值）

桥式全波整流电路

优势：
  • 正负半周都能利用，效率高
  • 输出脉动小，易于滤波
  • 输出频率是输入的 2 倍
V_out = 2 × V_peak / π ≈ 0.9 × V_rms

限幅（削波）电路

工作原理：
  • V_in > V_ref + 0.7V：D1 导通，输出被钳在 V_ref + 0.7V
  • V_in < -V_ref - 0.7V：D2 导通，输出被钳在 -V_ref - 0.7V
  • 中间区域：两个二极管都截止，输出等于输入

稳压二极管电路

稳压原理：
  • V_in 变化 → I_R 变化 → R 上压降变化
  • V_out = V_in - I_R × R
  • 稳压管在击穿区：I_Dz 变化大，但 V_Dz 几乎不变
  • 所以 V_out ≈ Vz 保持稳定
R = (V_in - Vz) / (Iz + I_L)
I_L = Vz / R_L

BJT 偏置电路

固定偏置电路（基极偏置）

特点：
  • 电路简单，只用一个偏置电阻
  • Q 点不稳定，受温度影响大
  • 温度↑ → β↑ → I_C↑ → 可能饱和失真
  • 只适合温度变化小、要求不高的场合

分压偏置电路（稳定工作点）

为什么稳定？
  • V_B 由 R_B1、R_B2 分压固定
  • 温度升高 → I_C 增大 → V_E = I_E × R_E 增大
  • V_BE = V_B - V_E 减小 → I_B 减小 → I_C 减小
  • 形成负反馈，自动稳定 Q 点
设计要点：
V_B >> V_BE（通常 V_B = 3~5 V_BE）
I_1 >> I_B（流过分压电阻的电流远大于基极电流）

共射放大电路

基本共射放大电路

电路分析步骤：
  1. 静态分析：画直流通路，求 I_BQ、I_CQ、V_CEQ
  2. 动态分析：画交流通路（电容短路），求 A_v、R_i、R_o
  3. 判断失真：检查 Q 点是否在放大区中心

分压偏置共射放大电路

C_E 旁路电容的作用：
  • 直流：C_E 开路，R_E 起稳定 Q 点作用
  • 交流：C_E 短路，R_E 被旁路，增益提高
  • 没有 C_E：增益会降低 (1+β)R_E/r_be 倍

共集电极电路（射极跟随器）

射极跟随器电路

为什么叫"跟随器"？
  • 输出电压 ≈ 输入电压（增益 ≈ 1）
  • 输出"跟随"输入变化
  • 不放大电压，但放大电流（功率增益）
A_v = (1+β)(R_E//R_L) / [r_be + (1+β)(R_E//R_L)] ≈ 1
R_i = R_B // [r_be + (1+β)(R_E//R_L)]（很高）
R_o = R_E // [r_be/(1+β)]（很低）

射极跟随器的应用

典型应用：
  • 多级放大器的输入级（提高输入阻抗）
  • 多级放大器的输出级（降低输出阻抗）
  • 阻抗匹配（最大功率传输）
  • 电压表输入级（减少对被测电路的影响）

MOSFET 放大电路

共源放大电路（N沟道增强型）

MOSFET vs BJT 放大电路：
  • MOSFET 输入阻抗极高（栅极几乎不取电流）
  • 不需要输入偏置电流，电路更简单
  • 跨导 g_m 通常比 BJT 的 β/r_be 小
  • 适合高阻信号源、集成电路

共漏放大电路（源极跟随器）

源极跟随器 vs 射极跟随器：
  • 两者功能类似：电压跟随、阻抗变换
  • 源极跟随器输入阻抗更高（栅极不取电流）
  • 源极跟随器输出阻抗可能稍高
  • 选择取决于具体应用和信号源特性

电源电路

线性稳压电源

线性稳压电源流程：
  1. 变压器：将 220V 交流降压到合适电压
  2. 整流：桥式整流将交流变成脉动直流
  3. 滤波：电容滤波平滑脉动
  4. 稳压：三端稳压器输出稳定直流

开关稳压电源（Buck 降压）

Buck 降压原理：
  • MOSFET 导通时：电流流过电感，电感储能
  • MOSFET 截止时：电感释放能量，通过续流二极管形成回路
  • 通过 PWM 控制占空比 D，调节输出电压
  • V_out = D × V_in（D 为占空比）
